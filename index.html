An AI game recommender, built with a collaborator: a FastAPI/PostgreSQL backend and Next.js frontend that rank IGDB's game catalog against a user's filters (platform, genre, length via HowLongToBeat data), then generate a live, personalized "why you'll like it" explanation with Claude for each result.
